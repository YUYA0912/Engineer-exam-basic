技術士一次 基礎科目 FINAL 250 - PWA版

使い方
1. このフォルダの中身をHTTPSで公開してください。
2. iPhoneのSafariで公開URLを開きます。
3. Safariの共有ボタン →「ホーム画面に追加」。
4. ホーム画面のアイコンから起動すると、ChatGPTの枠なしで独立表示されます。
5. 初回読み込み後はオフライン利用できます。

重要
- service workerによるオフライン機能は file:// では動きません。
- GitHub Pages / Netlify / Cloudflare Pages などHTTPS配信が必要です。
- 学習記録は端末のブラウザ保存領域に入ります。アプリ内のバックアップ機能も併用してください。
